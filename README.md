# Líf

*Ferðalag í gegnum liti, löngun, líf og list.*

Gagnvirk HTML5-upplifun: blómaengi, fuglar, haf og öldur sem skella á svartri sandströnd. Heill sólarhringur líður á 90 sekúndum og stýrir lit himins og hafs, stöðu sólar og tungls, skýjunum og norðurljósunum.

Tíu kaflar byggðir á rannsóknum um vellíðan, gleði og sköpun: nærvera, andardráttur, blár hugur, litir, lotning, leikur, þakklæti, tengsl, að gefa og tilvist. Heimildir eru á síðunni sjálfri (síðasti kafli → *Heimildir*).

## Keyra

Allt er í einni skrá, `index.html`. three.js kemur af CDN, svo netsamband þarf.

- Opnaðu `index.html` beint í vafra, eða
- keyrðu litla vefþjóna: `python3 -m http.server` og farðu á http://localhost:8000
- Til að birta á netinu: kveiktu á **GitHub Pages** fyrir þessa geymslu (Settings → Pages → branch).

## Hljóð

Engar hljóðskrár. Brimið, vindurinn, fuglasöngurinn, mávarnir, engispretturnar á nóttunni og mjúki hljómurinn eru búin til í rauntíma með Web Audio. Öldubrotið heyrist á nákvæmlega sama augnabliki og aldan brotnar á skjánum.

## Samspil

- **Snertu engið** til að sá blómum. **Dragðu** til að líta í kringum þig.
- Örvatakkar fletta á milli kafla.
- Ljósin (þakklæti) og stjörnurnar (óskir) geymast í vafranum þínum til næstu heimsóknar.
